# proto

Prototype builds. Self-contained HTML — no build step, open the file in a browser.

## Current

- `matchmaking-prototype-standalone.html` — Matchmaking prototype, standalone.

## Naming

Deliverables follow `<What it is> (<version>) - Matchmaking.html` in the project
folder; in the repo they are lowercased and hyphenated.

Superseded builds move to `old-versions/`; fix their relative `src=`/`href=`
paths with a `../` prefix so they still run from the subfolder.
