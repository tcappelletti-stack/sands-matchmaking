# flows

Annotated user-flow prototypes — one folder per flow, each with its own `index.html`.

Named by epic where one exists (`flows/epic1/`), otherwise by ticket (`flows/PROD-1556/`).

Each flow is a self-contained single-file HTML page of state-and-transition frames:
what the screen looks like before, during and after the interaction, with the
reasoning annotated beside it.
